# Maison Collective

Maison Collective is a React application built with TanStack Start, Vite, TypeScript, and Tailwind CSS.

## Development

You need Node.js 22.12 or newer and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- TanStack Router and Query
- Nitro
